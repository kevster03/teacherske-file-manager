┌─────────────────────────────────────────────────────────────────────────────┐
│ REQUIRED FIELDS (Must have values in every row)                            │
└─────────────────────────────────────────────────────────────────────────────┘

  title               Any text
  file                Full URL: https://example.com/file.pdf
  level               EXACT KEY (see table below)
  grade               Auto-normalized (see examples below)

┌─────────────────────────────────────────────────────────────────────────────┐
│ OPTIONAL FIELDS (Can be empty)                                             │
└─────────────────────────────────────────────────────────────────────────────┘

  description         Any text
  version             Text (e.g., "2026 Edition")
  subject             Text (e.g., "Mathematics")
  featured_image      Image URL: https://example.com/image.jpg
  author              WordPress username or email

┌─────────────────────────────────────────────────────────────────────────────┐
│ LEVEL KEYS (Must use EXACT lowercase with underscores)                     │
└─────────────────────────────────────────────────────────────────────────────┘

  early_years         → Playgroup, PP1, PP2
  lower_primary       → Grade 1, Grade 2, Grade 3
  upper_primary       → Grade 4, Grade 5, Grade 6
  junior_secondary    → Grade 7, Grade 8, Grade 9
  senior_secondary    → Grade 10, Grade 11, Grade 12

┌─────────────────────────────────────────────────────────────────────────────┐
│ GRADE FORMAT (Flexible - auto-normalized)                                  │
└─────────────────────────────────────────────────────────────────────────────┘

  For Grades 1-12:
    ✅ 7              → Grade 7
    ✅ grade 7        → Grade 7
    ✅ grade7         → Grade 7
    ✅ Grade 7        → Grade 7 (correct format)
    ✅ GRADE 7        → Grade 7

  For Early Years:
    ✅ pp1            → PP1
    ✅ PP1            → PP1 (correct format)
    ✅ playgroup      → Playgroup
    ✅ Playgroup      → Playgroup (correct format)

┌─────────────────────────────────────────────────────────────────────────────┐
│ EXAMPLE CSV ROWS                                                            │
└─────────────────────────────────────────────────────────────────────────────┘

Minimum Required:
title,file,level,grade
Grade 7 Math,https://example.com/math.pdf,junior_secondary,7

All Fields:
title,description,file,level,grade,version,subject,featured_image,author
Grade 7 Math,Algebra notes,https://example.com/math.pdf,junior_secondary,7,2026 Edition,Mathematics,https://example.com/img.jpg,admin

┌─────────────────────────────────────────────────────────────────────────────┐
│ COMMON MISTAKES                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

  ❌ Junior Secondary     → ✅ junior_secondary
  ❌ junior-secondary     → ✅ junior_secondary
  ❌ /files/doc.pdf       → ✅ https://example.com/files/doc.pdf
  ❌ Grade 7 + lower_primary  → ✅ Grade 7 + junior_secondary

┌─────────────────────────────────────────────────────────────────────────────┐
│ LEVEL-GRADE VALIDATION                                                      │
└─────────────────────────────────────────────────────────────────────────────┘

  Grade MUST match level!

  ✅ CORRECT:                    ❌ WRONG:
  junior_secondary + Grade 7     junior_secondary + Grade 4
  upper_primary + Grade 5        upper_primary + Grade 7
  early_years + PP1              early_years + Grade 1

┌─────────────────────────────────────────────────────────────────────────────┐
│ FILE REQUIREMENTS                                                           │
└─────────────────────────────────────────────────────────────────────────────┘

  Format:      .csv file
  Encoding:    UTF-8 (recommended)
  Max Size:    10MB
  Delimiter:   Comma (,)
  Header Row:  Required (first row)

┌─────────────────────────────────────────────────────────────────────────────┐
│ IMPORT BEHAVIOR                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

  • All documents imported as DRAFT (review before publishing)
  • Featured images downloaded to WordPress media library
  • Invalid rows skipped with error message
  • Valid rows imported successfully
  • Summary shows: imported count + error list

┌─────────────────────────────────────────────────────────────────────────────┐
│ QUICK START                                                                 │
└─────────────────────────────────────────────────────────────────────────────┘

  1. Go to: Documents → Import CSV
  2. Click: Download Template
  3. Edit template with your data
  4. Save as CSV (UTF-8)
  5. Upload and follow mapping wizard
  6. Import → Review drafts → Publish
